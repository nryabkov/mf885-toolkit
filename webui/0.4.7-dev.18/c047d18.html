What the modem can report

One universal read collects the router's existing status1, wan and Engineer_parameter models. No separate modem transport or command console is involved. A field appears only when the current radio mode and firmware return it.

Observed on this MF885 Device, session and LTE

  • Model, hardware revision and firmware version; current SIM state and registration code; radio access mode/submode, connection state, PDP/IP type and stock signal index.
  • LTE band, downlink and uplink EARFCN, downlink bandwidth and PCI.
  • LTE RSRP, RSRQ, SINR, RSSI and CQI, plus main/diversity antenna RSRP and RSRQ. RSRP/RSRQ are converted only from signed values or the reviewed report indices; SINR/RSSI remain raw.
  • Battery percentage and the current raw battery/charger/output/cable fields; total/session transmitted and received bytes plus cellular connection duration.

Router status schema Identity, WAN and local radio

  • Device name, model, hardware revision, firmware version and build/version date.
  • SIM state; registration code with possible not-registered/home/searching/denied/roaming values; operator, radio mode/submode, PDP state/type and last PDP error/cause.
  • Selected uplink protocol, WAN link and connection state; local access-point enabled/channel; repeater state and signal.
  • Battery percentage, raw battery level/state, charger state/current, output current and cable detection; WAN traffic counters and connection-duration fields.

Firmware schema UMTS / 3G fallback

  • MCC/MNC, LAC, RAC, URA and cell identity; PSC/cell parameter ID and UARFCN.
  • RSCP, CPICH Ec/N0, UTRA RSSI, Srxlev/Squal and modem transmit power.
  • HSDPA/HSUPA support, attachment-detection and HCS flags, nominal mode, CS/PS/UTRAN DRX cycles and T3212/T3312 timers.

Firmware schema GSM / 2G fallback

  • MCC/MNC, LAC/RAC, band, serving and traffic-channel ARFCN, BSIC and cell identity.
  • Signal level including full/sub values, receive quality full/sub, timing advance and transmit-power level.
  • Channel type/mode/timeslot, hopping state/HSN/group, cell priority and C1/C2/C31/C32 criteria.
  • Channel-assignment and handover attempts/successes, forbidden-location state, packet-idle/PBCCH/EGPRS flags, NCO/NOM/NCC permissions, paging and radio-link timers.

Firmware schema GPRS / EDGE

  • Attached state, attach and service type, network mode/control, MAC mode and active PDP-context count.
  • Uplink/downlink coding scheme, modulation, timeslots and throughput, plus transmit power and C-value.
  • EGPRS support, link-quality measurement mode, BEP period, USF granularity and GMM reject cause.

Private when returned WAN details

  • SIM/subscriber identifiers, device serial/unit identifiers, serving operator, MCC/MNC, Cell ID/eUTRAN/ECGI and TAC/LAC.
  • Configured and active APN, WAN authentication type and username, IPv4/IPv6 addresses, gateways and DNS; selection modes and local/repeater SSIDs.
  • Current values are deliberately omitted from this static Help text and must never be copied into public logs because they can identify the subscriber, location or local network.

About TTL and this version
          
TTL limits how far an IPv4 packet can travel. Routers along its route can reduce it, so the destination may receive a value below 64.

          
64 and Off were observed with UDP traffic in both directions on the preceding firmware with the same native code. Other protocols and custom values are still being checked. This editor is a development candidate awaiting its own router test.

          
Use one settings session at a time. The displayed value is the last router response, not continuous monitoring. If a change is not confirmed, read the setting again before deciding what to do.
