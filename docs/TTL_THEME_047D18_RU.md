# Community 0.4.7-dev.18: TTL и тема

Экспериментальная версия для MF96 Ver.D, vendor base 2.5.94, SoC 88MP1802
(ARM9, ARMv5TE, ARM/Thumb-1, little-endian EABI5, soft-float).
Публикуются исходники и офлайн-сборщик, без образа и команд прошивки.

## Изменения

- TTL: ручное целое число 1–255 или Off. Начальное значение после загрузки — 64.
  Это не случайный TTL. Настройка хранится в RAM, а не во flash.
- Применение: явное чтение, проверка ревизии, один POST и отдельное подтверждающее
  чтение. Автоматических повторов записи нет. Неканонические числа отклоняются.
- Тема System (по умолчанию), Light или Dark. Выбор сохраняется локально в
  браузере; переключение темы не пишет настройки роутера.
- Сохранены консоль AT/USSD и обработка истечения сессии. CPU выводится из
  экспериментального счётчика; его точность не подтверждена.

Открыть `/c047d18.html`, войти обычным паролем роутера. В разделе TTL сначала
прочитать состояние, выбрать Manual и число либо Off, затем применить и дождаться
подтверждения. Выбор темы находится в интерфейсе. Для TTL 1 обычный интернет
может перестать работать из-за истечения TTL на следующем маршрутизаторе.

## Что действительно проверено

15 сентября 2026 завершена ограниченная проверка точного dev18 на одном устройстве:
загрузка и восстановление доступа, совпадение всех 208 обслуживаемых ресурсов,
авторизованный интерфейс на мобильном и широком экране, переключение темы.
Новый native-компонент относительно dev17 отсутствует.

Пакеты IPv4 UDP с исходными TTL 32 и 96 наблюдались на двух внешних хостах:

| Режим | Входящие к клиенту за MF885 | На удалённом хосте |
|---|---|---|
| 64 | 64 для обоих пакетов | 50 для обоих пакетов |
| 255 | 255 для обоих пакетов | 241 для обоих пакетов |
| Off | 18 и 82 | 18 и 82 |
| 1, отдельная входящая проверка | 1 для обоих пакетов | исходящие пробы с MF885 не отправлялись |

Для отдельной проверки TTL 1 UDP-сокеты были открыты при TTL 64 и сохранены
при переключении в 1. Это дало положительное наблюдение двух входящих пакетов.
Ранее исходящие TTL 1 не достигли удалённого наблюдателя; это согласуется с
истечением TTL по пути, но не является измерением на физическом сотовом выходе.
Off согласуется с уменьшением TTL на 14 между выбранными точками наблюдения.
После испытания подтверждены TTL 64 и удаление временных маршрутов.

## Ограничения

Это ограниченные наблюдения одного устройства и одного сетевого пути,
не общая аппаратная квалификация. Нет физического захвата на сотовом выходе,
доказательства для всех протоколов/операторов, стабильности USB на длительном
интервале или универсального восстановления после неудачной прошивки.
Одиночная потеря пакета в ранней попытке не повторилась; первопричина неизвестна.
Причина наблюдавшихся перенумераций USB также не установлена.
Показание CPU 99,9% и символ замены в имени оператора остаются известными
ограничениями; независимой калибровки CPU и исходных байтов для диагноза кодировки
недостаточно. Не считать эти показатели доказанными измерениями.

## Сборка и совместимость

`python3 -B tools/mf885_build_variant.py --variant community-0.4.7-dev.18
--output-dir out/dev18 --acknowledge-brick-risk` (одной строкой), с собственными
исходными файлами согласно [инструкции сборки](BUILD_FIRMWARE.md).
`MF885_TOOLCHAIN_ROOT` задаёт каталог точного Clang18/LLD18; по умолчанию
`input/clang18`. Проверяются хеши исходников, инструментов, native-компонента,
ELF и веб-ресурсов. Пины dev16/dev17 нужны только для цепочки построения dev18;
эти промежуточные версии не объявляются отдельными публичными релизами.

Новый образ привязан к предоставленному устройству. Его офлайн-проверка не
переносит аппаратные результаты эталона на другой образ или другую ревизию.
Старые версии и их хеши сохранены. Причина прежнего ограничения редактора
TTL значениями 64/Off — браузерная проверка аргумента; native-контракт уже
поддерживал 1–255. В dev18 расширен редактор, без изменения native TTL-кода.
