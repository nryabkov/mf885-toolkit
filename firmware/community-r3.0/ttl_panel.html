Custom TTL

Write any exact IPv4 TTL from 1 through 255.

What this changes

  • Forwarded IPv4 traffic only; packets created by the router itself are unchanged.
  • IPv6 is unchanged.
  • Incoming TTL 0 or 1 is never rescued by the extension.
  • Allowed values are Off or any canonical integer from 1 to 255.
  • One click sends one state change and one readback. There is no automatic retry.
  • If readback is lost, changes lock until a fresh read proves the current state.
