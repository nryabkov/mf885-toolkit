What the screen proves
Readback
The router retained the exact command=ttl and requested arg between separate HTTP requests.
Not implied
The screen does not infer packet rewriting from that retained value. Release qualification observes an actual packet separately.
Failure
An incomplete, malformed or unexpected response locks writes and shows an error ID. No request is retried automatically.
Earlier builds
R3.0–R3.7 tried to publish a synthetic output value from native callbacks and could hang or reset. R3.8 proved safe entry and return with no setter. R3.9 reads stock-retained input and writes one private state byte.
