What this increment proves
Earlier
R3.8 returned safely because its four-byte callback called, read and wrote nothing. R3.9 combined generic getter/free, a private state write and a packet hook; its first valid SET lost the response and RNDIS re-enumerated.
R4.0
The callback validates the exact phase-3 context, reads its request tree, resolves command and arg with the byte-pinned stock helpers, treats both values as borrowed and always returns zero.
Boundary
There is no generic property getter/free, property setter, custom state, GET callback or forwarding hook. A complete response with stable identity proves only that the callback survived this exact request; the lookup branch itself is not live-observable. TTL remains unavailable.

The existing router UI, Messages, Engineering mode, hidden debug profile and stock packet forwarding remain unchanged.
